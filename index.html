About

This tool allows you to change a phased array's geometry, element spacing, steering position, add sidelobe tapering, and other features.

This demo was created by Jason Durbin, who is currently an antenna engineer at Amazon Leo.

Usage and Notes

  • Element [new Aug. 2026] defaults to isotropic over the front hemisphere, so calculated directivity is about +3 dBi for a uniform pattern. The Element section can instead apply a cosn power pattern: you set the peak broadside gain in dBi (minimum 3.01 dBi, i.e. 10·log102), and n = 10(G/10)/2 − 1 is chosen so the pattern conserves power. Cosn is zero behind the array, so U/V samples outside the unit circle are dark. That pattern multiplies the array-factor intensity before directivity, EIRP, and beam metrics. PEC dipole is a finite short dipole over infinite ground: mutual Z and the isolated element pattern come from the same Green function, Matching is hidden, and you set height h, length ℓ, radius a (in wavelengths at f0), a real port Z0, and Self X (a series reactance added to every diagonal of Z). Match sets Z0 to Re(Z11) and Self X to −Im(Z11) of a single isolated element (not a scan match). Realized gain is directivity × accepted/stimulated, so it includes mismatch when Matching is not Isolated (or whenever PEC dipole builds S,T). Aperture efficiency is realized gain over the geometric bound 4πA/λ2 and can exceed 100% for small arrays with a directive element.
  • Matching Isolated uses geometric array factor. Per-port, Common Z0, and Propagation estimate an S-matrix from radiated-power overlap. Self X (Ω) is a common diagonal residual reactance on Z (default 5 Ω). Per-port and Common Z0 optionally add a phenomenological pairwise overlay: jXnn(dmin/ρ)α cos(β(ρ/dmin−1)) (1+A cos 2φ), with φ = atan2(Δy, Δx). Mutual X is signed (positive inductive); Decay α is the power-law falloff; Oscillation β is radians of extra phase per extra nearest-neighbor spacing at f/f0 = 1 (multiplied by frequency scale); Location A makes equal-distance pairs along x and y differ. β = 0 and A = 0 recover the older same-sign tail. Propagation replaces that overlay with a complex-propagation kernel: phase 2π(f/f0)(√εx|Δx| + √εy|Δy|) and envelope exp(−αλ ρ), normalized so the closest pair is Mutual X; it always uses a common real Z0. The port reference z0 is always real. Per-port solves individual z0,p = Re(Zin,p) so resistance is matched; leftover reactance stays in Z and in Sii. Common Z0 and Propagation use one real reference on every port (default 45 Ω), so |Sii| varies over the array. Matching does not apply when Element is PEC dipole (Green Z replaces these toys); that mode has its own real Z0, series Self X, and Match.
  • Domain Spherical, U/V, and Ludwig3 plot the 2-D far-field. Z and S plot the matched-system matrices: Re(Z) and Im(Z) side by side with a shared Ω colorbar, and 20 log10|Sij| in dB. Those views still use frequency scale (and the active Matching model's Self X / Mutual X / kernel knobs) and do not require switching away from Isolated.
  • The mesh can be made finer by increasing Points. However, increasing the number of points may result in laggy performance.
  • Clicking (or long pressing) elements in the phase/attenuation plots allows you to manually set phase/attenuation. Be sure to select "enable override." Additionally, the attenuation pop-up allows you to disable elements.
  • Hovering (or touching) the 2-D farfield plot or geometry plots will show the value of the plot under the cursor.
  • Power [new Aug. 2026] is either full-scale per-element drive or total array power. Taper, manual attenuation, and quantization scale each element by |ai|2. Available power is N times full-scale per-element drive. Stimulated (used) power is Pant Σ|ai|2. When Matching is Isolated, power utilization is stimulated/available. When a matched model is selected, accepted power is stimulated × (1 − Γ) from the estimated S-matrix, and utilization is accepted/available. If total array power is selected, per-element power is Ptot / Σ|ai|2. EIRP is directivity times accepted power (equivalently realized gain times stimulated). Power metrics and EIRP use the EIRP unit.
  • Illumination [new Aug. 2026] can be used to estimate different types of arrays. For example, a reflectarray would use a spherical wave, traveling waves would use guided wave, etc.
