About

This tool allows you to change a phased array's geometry, element spacing, steering position, add sidelobe tapering, and other features.

This demo was created by Jason Durbin, who is currently an antenna engineer at Amazon Leo.

Usage and Notes

  • Element [new Aug. 2026] defaults to isotropic over the front hemisphere, so calculated directivity is about +3 dBi for a uniform pattern. The Element section can instead apply a cosn power pattern: you set the peak broadside gain in dBi (minimum 3.01 dBi, i.e. 10·log102), and n = 10(G/10)/2 − 1 is chosen so the pattern conserves power. Cosn is zero behind the array, so U/V samples outside the unit circle are dark. That pattern multiplies the array-factor intensity before directivity, EIRP, and beam metrics. Aperture efficiency uses the geometric aperture bound 4πA/λ2 and can exceed 100% for small arrays with a directive element.
  • The mesh can be made finer by increasing Points. However, increasing the number of points may result in laggy performance.
  • Clicking (or long pressing) elements in the phase/attenuation plots allows you to manually set phase/attenuation. Be sure to select "enable override." Additionally, the attenuation pop-up allows you to disable elements.
  • Hovering (or touching) the 2-D farfield plot or geometry plots will show the value of the plot under the cursor.
  • Power [new Aug. 2026] is either full-scale per-element drive or total array power. Taper, manual attenuation, and quantization scale each element by |ai|2. Available power is N times full-scale per-element drive. Stimulated (used) power is Pant Σ|ai|2. Power utilization is stimulated/available, shown as % and dB. If total array power is selected, per-element power is Ptot / Σ|ai|2. EIRP is directivity times stimulated power. Power metrics and EIRP use the EIRP unit.
  • Illumination [new Aug. 2026] can be used to estimate different types of arrays. For example, a reflectarray would use a spherical wave, traveling waves would use guided wave, etc.
